Genome Scanner

Topics

Bioinformatics, pattern matching, parallel I/O

Prerequisites Concepts

MPI I/O, parallel loops (or GPU kernels), metering, speedup, computational efficiency

Instructions

Given a genome and a subsequence string, the Genome Scanner is intended to find each instance of the substring within the genome. It returns the number of occurrences of that subsequence along with the indices where these occurrences were found. This program is designed specifically for DNA sequences using the standard nucleotide alphabet (A, T, C, G), though the underlying algorithm could be used for general string matching.

The assignment is:
  1. Starting with one of the sequential programs for MPI provided below, add internal timing calls (e.g., using MPI or OpenMP's Wtime functions) to the beginning and end of the sequential program to measure precisely how long it takes to solve the problem. Record that time in a spreadsheet, indicating that it is the time to solve the problem using 1 processing element (PE).
  2. Use parallel techniques to convert the sequential program into a parallel program that solves the problem.
  3. In your spreadsheet, record the raw times your parallel solution requires to solve the problem using a given number of PEs. For each PE value, calculate the speedup and computational efficiency. Then create three well-labelled line-charts that (respectively) show the relationship between the number of PEs and:
    1. the raw times,
    2. the speedup values, and
    3. the computational efficiency values.
    Each chart should plot the number of PEs on the horizontal axis and the other value (time, speedup, efficiency) on the vertical axis. Depending on which parallel software option you are using (see below), your instructor may provide additional details regarding their precise expectations, such as the number of PEs you are to use.
  4. Write a 1-page report in which you explain what your charts reveal about the relationships between the number of PEs and the raw time, the speedup, and the computational efficiency of your parallel program.
  5. Expand on the MPI result by performing computations using a multithreading technology.
  6. Once an MPI + multithreading solution has been reached, try performing the computations with a GPU offloading technology. Compare the speedup/efficiency results of each resulting program.

Deliverables

Using the submission process at your institution, turn in:
  1. Your 1-page report.
  2. Your three charts (one per page, landscape, maximized to fill the page).
  3. Your spreadsheet, showing the data used to generate your charts.
  4. The source code of your parallel program.
